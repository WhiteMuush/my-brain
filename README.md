# My-Brain

Vault Obsidian de documentation rapide : Terraform, Ansible et sécurité. Chaque note dit comment on fait, sans plus.

## Utiliser le vault

1. Cloner le dépôt :
   ```bash
   git clone https://github.com/WhiteMuush/my-brain.git
   ```
2. Dans Obsidian, choisir **Ouvrir un dossier comme coffre**, puis le dossier cloné.
3. Partir de la note **My-Brain**, ou ouvrir la vue graphe.

Aucune synchronisation n'est fournie : le clone reste local.

## Structure

- `My-Brain.md` liste les thèmes.
- Un dossier par thème, avec une note du même nom qui liste ses notes.
- Chaque note commence par `Thème : [[Parent]]`.
- Le nom d'une note commence par le nom de son thème.
